# Tests

This directory contains project verification work.

## Folders

- [`spikes/`](spikes/) contains short architecture experiments required for
  P2. The current experiment is [`spike1.js`](spikes/spike1.js).
- [`OtherTests/`](OtherTests/) is reserved for future unit, integration,
  system, and acceptance tests.

Spike results should document the question, setup, command, measurements, and
conclusion. Production application code belongs in `src/`, not in this folder.
